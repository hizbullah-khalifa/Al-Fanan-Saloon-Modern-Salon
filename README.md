# Al Fanan Saloon 💇‍♂️✨

A modern, responsive, and elegant salon website built with **React.js and Vite** for **Al Fanan Saloon**.

The website provides a professional online presence for the salon, showcasing its services, beauty treatments, and overall brand experience through a clean and user-friendly interface.

## 🚀 Features

* 🎨 Modern and attractive UI
* 📱 Fully responsive design
* 💇‍♂️ Salon services showcase
* ✨ Elegant and professional layout
* ⚡ Fast performance with Vite
* ⚛️ Built with React.js
* 🧭 Smooth and user-friendly navigation
* 📞 Contact and salon information

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* Tailwand Css
* Framer Motion
* Responsive Web Design

## 📦 Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project:

```bash
cd al-fanan-saloon
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
